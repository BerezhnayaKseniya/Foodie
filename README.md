# Foodie – Recipe Application

Foodie is a recipe application developed with React Native and Expo as part of a course project.

## Run the Application in Expo Snack

**[Open Foodie in Expo Snack](https://snack.expo.dev/@git/github.com/BerezhnayaKseniya/Foodie@main)**

If the direct link does not open, follow these steps:

1. Visit https://snack.expo.dev/
2. Select **Import Git Repository**.
3. Enter the repository URL: `https://github.com/BerezhnayaKseniya/Foodie`
4. Select the `main` branch and leave the folder path empty.
5. Click **Import repository**.
6. Select the **Web** tab to run the application in your browser.

## Features

- Browse and filter recipes by category.
- View ingredients, cooking instructions, preparation time, servings, calories, and difficulty.
- Add and remove recipes from favorites.
- Create personal recipes with images, ingredients, and instructions.
- View, edit, and delete personal recipes.
- Navigate between application screens.

## Technologies

- React Native
- Expo SDK 51
- React Navigation
- Redux
- AsyncStorage
